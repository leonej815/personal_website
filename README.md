Joseph Leone - Technical Portfolio
A custom built website to act as a resume and portfolio showing my information and projects.

Tech Stack
* Frontend: HTML5, CSS, Javascript.
* Backend: Python 3.x.
* Libraries: PyMuPDF for PDF-to-image processing, Pillow for image manipulation

Key Features
* Responsive Viewer: There is a gallery of coursework that uses PDF iframe for desktop and a long JPG image of a PDF for mobile. 
* Asset Sync Script: A Python script that changes all the PDF files I add into associated JPG files.
